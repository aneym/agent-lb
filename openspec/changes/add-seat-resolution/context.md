# Seat resolution decisions

`git show` reads a table and its definitions at one commit: a run can pin its rules, cannot read a half-installed version and does not mix in local live overrides. The installed managed table is a fallback without APPLIED (owner steer B2, 2026-09-27): a missing sync job must not stop work. Every answer labels its source and table hash, so this fallback is visible.

`unknown_class` and `unresolved_model` fail loudly rather than guessing. When class entries disagree, even if one is implement, the caller must name `--class implement`; silently preferring it violates the no-guess design.

`needs_test_run` belongs on the auditor seat: it describes the auditor harness, not the author's vendor or the runner's model. This change supersedes the pending change's "Preserve off-default seats" scenario and removes it.
