# Fetch measured Kimi Coding quota

Kimi Coding exposes quota telemetry, but Agent LB does not fetch it and synthesizes full primary capacity when usage is absent. Add the provider usage client from the official Kimi CLI contract, connect scheduled/operator refresh, persist measured windows and resets, and render real remaining values in the native app while keeping unknown data unknown. Preserve Kimi and Muse grouping under Other. No message-body, billing, credential custody, or paid routing change.
