## Why

The routing canon must reflect the measured factory ladder, cross-vendor review, and fixed stage effort rather than older seat defaults. The policy should be independently verifiable without using a machine's installed home.

## What Changes

- Make Sol medium the default implementation and mechanical seat, with a measured pace-gated Opus fallback and dated evidence for off-default seats.
- Require fresh cross-vendor audit and release facts for every unit, and a three-lens any-fail money-path review.
- Add stage effort, second-opinion and public-text checks to source-only routing verification.
- Manage the three default GPT seat definitions through the policy installer.
- Update routing prose, adapter and seat definitions; preserve local overrides and leave the runtime router unchanged.

## Capabilities

### New Capabilities

- `coding-agent-routing`: Define and verify factory routing principles.

### Modified Capabilities

- `deployment-installation`: Manage default GPT seats safely.

## Impact

The policy table, routing canon, seat definitions, installer and verifier change. Open Factory's static and Jev menus must be updated separately to use the new canon. Every machine must reinstall the policy; the managed CLAUDE.md block changes. No runtime router change is claimed.
