This is an advisory snapshot, not an admission or provider-health signal. The numerator and denominator use Anthropic's three disjoint input-token categories, rather than treating `input_tokens` alone as the complete prompt. For example, 40 cache-read plus 20 cache-creation plus 40 uncached input tokens yields 40%, so status alerts. A successful log with missing token categories makes the hour unknown; a silent hour is not a 0% cache hit rate. The endpoint uses the same dashboard authentication as account status, and cache-summary failures leave the existing health/account snapshot intact.
