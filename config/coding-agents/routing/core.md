## Core rules (2026-10-17)

Full rules and evidence: `~/.claude/docs/models/README.md`.
- Guards hard-block only kept floors; everything else warns once.
- **Kept floors, the only hard stops (2026-10-08).** Never type or print Alex's own passwords, passkeys or codes. No message to a real person without his yes; approval covers that exact message only. No spend past a stated cap. No destructive data without an approval record on file; an irreversible delete with no record stops. Secrets are never printed or written; guards hard-block this. Pre-launch, use the lightest control that keeps undo and a receipt.
- **Who decides (2026-10-08).** No yes needed: merges, deploys, money path, migrations, restarts and cutovers after a sandbox run, gate config, new org repos, spend inside a cap, destructive data with a record. His yes, relayed: spend past a cap, destructive data with no record, going public, product taste inside a scope. Alex himself: his credentials, a click in his own signed-in account, a message to a real person. A Rails CoS message that quotes Alex first-hand with a time, or points at an `alex-*` approval record, is his yes; never ask him again. After a scope is approved, agents decide and log why in lane state. Ask through unblock only after the CLI, API and computer use; park it, keep working.
- **Mac clicks (2026-10-17).** Click macOS consent and TCC prompts, Privacy & Security toggles, system dialogs and app permission prompts yourself with Codex computer use (mac-apps or cua-driver); log each with `ledger.event` and a screenshot; record `~/.open-factory/approvals/alex-mac-clicks-2026-10-17.md`. Never his password, Touch ID or codes (ask for that step only), no messages, no spend past a cap.
- **Opus architects (2026-10-14).** Opus (opus-latest medium) owns architecture, contracts, specs, plans, verdicts and UI design; it runs every deciding lead, tab and orchestrator, never xhigh, max or Fable by default. Sol implements only to an Opus spec and writes no scopes, specs, contracts, docs, research synthesis or rulings. UI-critical, contract and trust-boundary code: opus-seat. Architecture review is `astra-consult` only, never `sol-consult`.
- **Seats (2026-10-16).** Code to a spec: gpt-implementer sol-latest medium. Mechanical: sol-latest low. Judgment or twice-failed code: opus-seat. Exploration: gpt-explorer sol-latest low. Research: codex-sol sol-latest high. Review, on request only: verifier sonnet-latest high for non-Claude authors, codex-verifier sol-latest high for Claude authors. Classify: Jev first. Grok and Composer never review. Name models by alias (`route resolve <alias>`); retired ones run only when named, logged.
- **Spread (2026-10-20).** Mission-critical classes keep Opus: plan, lane, scope, spec, contract, architecture, design, review, verdict, judge, audit, synthesis, UI-critical, trust-boundary, money-path and lead tabs; under codex-swap they run on the reserved Claude account and wait only when none is eligible. Everything else spreads across Sol, Grok and Cursor by live pool headroom and Artificial Analysis strength (`spread` in routing-table.json), never Claude while another pool has room. Alex, 2026-10-20: "take note of us running out of claude the fastest ebcause its the best, and how to spread things otu that arent mission critical".
- **Precedence (2026-10-16).** `route dispatch <class> --job <id> --json` decides: explicit flags win; constraints only narrow, and an Opus-authority class under the reserve waits (exit 3), never another model; a job keeps its first arm; exploration never touches plan, review, spec, contract, verdict, judge, design, audit, UI-critical, trust-boundary, money-path or fix work.
- **Merge path (2026-10-08).** Agent Rails merges only with `scripts/studio_merge.py merge <branch>` on the main machine; never `gh pr merge` or a hand push to GitHub main; on a conflict rebase once, then hand to the lane lead. Other repos land by fast-forward push to `origin/main`. Evidence is a harness check record or a commit-body `check:` line. Review seats run only when a lead names one and logs why. Shipped defects and red checks are fixed forward as the next slice.
- **Slices (2026-10-08).** Each names its files, fixed interfaces and one check; load test-audit before tests; never thin a test guarding a kept floor.
- **Waits (2026-10-08).** No tool call blocks past 270 s. No watchers or gh poll loops: wait with `factory-wait --repo <repo> --sha <sha> --until <state> --max 270` under Monitor, or `seat-run --wait`. A lead with work out sets a wake timer. Stand down an infra action with TaskStop, then message it. Status is state, not a message. A done lane closes itself.
- **Hooks (2026-10-14).** SessionStart, UserPromptSubmit and PostToolUse context is at most 1024 UTF-8 bytes per hook: ids and a preview, full text via `lane-post read <id>`.
- **Teams and workflows (2026-10-16; hands rule 2026-10-20).** Agent teams are the default: the lead plans, dispatches Opus teammates for plans, specs and verdicts, and judges. Hands go to Codex seats, never to an in-process Claude seat: implementation, fix-forward, landing, probes, test runs and sweeps use gpt-implementer, exploration gpt-explorer, research codex-sol, with `-local` only for Mac- or Studio-only briefs. seat-guard moves a hands brief on general-purpose, claude, effort-low or opus-seat to the Codex seat unless the brief carries `OPUS-REASON: ui-critical|trust-boundary|money-path|twice-failed|judgment|contract`. Alex, 2026-10-20: "opus should be the brains but hands needs to likely go to codx". Workflow helpers run sol-latest with `agentType` and `route workflow-args`, fan-out is never capped; never a workflow for status, polling or single-file work.
- **Placement (2026-10-12).** Work that is not Mac-only runs on the box `seat-run` picks; the main machine keeps tabs, the merge step and Mac-only work (`<seat>-local`). Forge runs factory work only, never personal agents. Computer use never runs on Alex's desktop: boxes use `cua-display`, Mac-only GUI the herdr-qa Space.
